# **App Name**: ApeChain Spaces

## Core Features:

- Spaces Schedule: Display a schedule of upcoming Twitter Spaces, filterable by day.
- Timezone Conversion: Allow users to filter Spaces by day and view them in their local timezone.
- User Preferences: User accounts to save timezone preferences and favorite spaces.
- Favorites List: Ability for users to mark Spaces as favorites and display them in a separate list.
- Admin Space Submission: Admin access to add new spaces with details like day, time, name, and project page link. Note: the link for the page is a tool used to include the URL of the spaces

## Style Guidelines:

- Primary color: Apecoin Blue (#0054FA) for the main branding and interactive elements.
- Secondary color: GN Blue (#002787) to complement the primary color and create depth.
- Background color: GM Blue (#E2F0FF) for a light and clean backdrop.
- Text color: Anchor Black (#000000) for readability against the light background.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and 'Inter' (sans-serif) for body text, for a modern and readable interface.
- Clean and organized layout with a clear hierarchy to easily browse the Spaces schedule.
- Subtle transitions and animations to improve user experience when filtering and adding spaces.
