# **App Name**: VibeStr Profit Prophet

## Core Features:

- Real-time ETH Price: Fetches and displays the current ETH price from a reliable API.
- Profit Calculator: Calculates break-even points, target prices, and net profits based on user inputs, considering fees.
- Investment Conversion: Uses current price of ETH to calculate investment value in USD
- Customizable Multipliers: Allows users to set target multipliers for profit calculation, including a custom option.
- Purchase History: Stores and displays a history of calculated purchases in local storage for future review. Supports deletion of individual purchase records.
- Dynamic Calculations: As the user inputs numbers, the app dynamically recalculates buy price and the current investment amount based on live conversion rates to keep numbers accurate as possible. Display of results.

## Style Guidelines:

- Primary color: Purple (#A855F7) to evoke a sense of magic, digital creativity, and profitability within the VibeStr ecosystem.
- Background color: Very dark blue-gray (#0A0615) to provide a high-contrast backdrop that makes UI elements pop.
- Accent color: Electric blue (#72D4FF) as a vivid counterpart to the primary color.
- Body and headline font: 'Space Grotesk' (sans-serif) for a computerized, techy, scientific feel.
- Use feather icons for a simple, modern aesthetic. Icons should match text in color.
- Use a centered layout with a maximum width for readability. Implement a card-based design with rounded corners and subtle shadows to create depth.
- Subtle animations, such as pulse effects on key elements or smooth transitions, to enhance user experience without being distracting.
